# Language Translation Tool

A simple language translation web app built with Python and Streamlit. It uses the MyMemory Translation API through the `requests` library to translate text between languages.

## Features

- Supports multiple languages, including English, Urdu, Hindi, Arabic, French, Spanish, German, Chinese, Japanese and Turkish
- Simple and clean interface with a lavender, white and purple theme
- Option to download the translated text

## Technologies Used

- Python
- Streamlit
- MyMemory Translation API
- requests

## How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Run the app:

```bash
streamlit run app.py
```
